| File | Description | Location |
|---------|-------------|-----|
| `README.md` | Description, quick start, links | Root |
| `CHANGELOG.md` | Version history (Keep a Changelog) | Root |
| `BACKLOG.md` | Project epics and stories | Root |
| `ROADMAP.md` | Vision and goals by version | Root |
| `AGENTS.md` | Project rulebook for agents and humans (see below) | Root |
| `CONTRIBUTING.md` | Contribution guide | Root |
| `SECURITY.md` | Security policy and reporting | Root |
| `LICENSE` | Project license | Root |
| `docs/adr/` | Architecture Decision Records | docs/ |
| `.github/copilot-instructions.md` | Copilot instructions for the project | .github/ |

## AGENTS.md — project rulebook

The first file every agent reads (Hermes, Claude Code DEV, Copilot) and the reference for
human contributors. Generated by `vibecoding-bootstrap/scripts/apply-template.sh`, then owned by
the project. Required sections:

| Section | Content |
|---------|---------|
| Project | purpose, type, stack, language (English, ADR-0002) |
| Commands | install / lint / test / build — Lint and Test identical to `.ai/orchestration.yaml` `validation.commands` |
| Repository map | where intent, decisions, tasks, runs, source and tests live |
| How work flows | PRD → ADR → task contract → DEV/REVIEW/TEST → human merge (ADR-0005); roles table |
| Conventions | commits, tests, scope discipline |
| Boundaries | **Always** / **Ask first** / **Never** |
| Definition of done | verifiable exit criteria |
| Type-specific rules | rules for `base`, `infra`, `ai`, `app` or `m365` |

Constraints: under ~1,500 tokens (Hermes and DEV read it in full on every task); an accepted
ADR overrides it; `CLAUDE.md` must not `@import` it (it would load into every session). Copilot
agent inventories do not belong here — they live in `.github/agents/`.

## Architecture Decision Records (ADR)

Format: `ADR-XXXX-title-in-kebab-case.md`

Structure of an ADR:
```markdown
# ADR-XXXX — Decision title

**Date:** YYYY-MM-DD
**Status:** Proposed | In Progress | Accepted | Rejected | Withdrawn | Deprecated | Superseded by ADR-YYYY
**Decision-makers:** <list>

## Context
## Decisions
## Consequences
## References
```

First ADRs to create:
- `ADR-0001` — Initial project decisions (generated by `init-adr.sh`)
- `ADR-0002` — Technical stack choice

## CHANGELOG

[Keep a Changelog](https://keepachangelog.com/en/1.0.0/) format:
```markdown
## [Unreleased]
### Added
### Changed
### Deprecated
### Removed
### Fixed
### Security
```

## BACKLOG

Recommended structure:
- **Epics** — large units of business value
- **Stories** — deliverable units of an Epic
- **Icebox** — unplanned ideas

## ROADMAP

Recommended structure by version:

```markdown
## v0.1-alpha — Goal: ...

- [ ] ...
```
